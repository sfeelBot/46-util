# bmp_rename_by_folder — processing.md

- 경로: `utils/bmp_rename_by_folder/`
  - `rename_bmp.py`: 유일한 파일, 실행 진입점 (GUI 없음)
- 목적: 상위 폴더 안에 `Test#A5-0000013` 형식의 하위폴더가 여러 개 있고, 각 하위폴더 바로 안에 `Test#A5-0000021-14-000_14_C4_2026.bmp` 처럼 폴더명과 유사하지만 숫자 부분이 다른 bmp 파일들이 있을 때, 파일명 앞부분(폴더명과 같은 형식: prefix+숫자)을 실제 하위폴더명으로 일괄 치환(rename)한다.
- 의존성: 없음 (표준 라이브러리 `os`, `re`, `csv`, `shutil`, `sys`만 사용)
- 버전: v1 (2026-07-13)
- 사용법:
  ```
  cd "E:\46 util"
  .venv\Scripts\python.exe utils\bmp_rename_by_folder\rename_bmp.py "D:\path\to\top_folder"
  ```
  - 인자 없이 실행하면 `input()`으로 경로를 물어봄.
  - 처리 후 콘솔에 하위폴더 수 / 이름변경 / 변경없음 / 에러 건수를 print로 요약 출력.
  - 입력받은 최상위 폴더에 `rename_log.csv`(utf-8-sig, 컬럼: 하위폴더/원본파일명/결과파일명/상태/사유) 저장.
- 알고리즘:
  - 최상위 폴더의 모든 하위폴더(전체, 첫번째만이 아님)를 대상으로 함
  - 하위폴더명을 정규식 `^(.+-)(\d+)$`로 파싱해 prefix(예: `Test#A5-`)와 숫자를 분리
  - 하위폴더 바로 안(재귀 아님)의 `.bmp` 파일 중 파일명이 `prefix+숫자`로 시작하면, 매치된 구간만 실제 폴더명 전체로 치환하고 나머지 뒷부분은 그대로 붙여 rename
  - 치환 결과가 원본과 같으면(이미 올바른 이름) rename 생략, 로그에 `no_change`
  - 폴더명 자체가 `prefix-숫자` 형식이 아니면 그 폴더는 통째로 건너뜀(`skip_folder`), 파일 처리 안 함
- Edge case 처리:
  - 파일명이 `prefix+숫자`로 시작하지 않음(패턴 불일치) → 해당 하위폴더 안의 `error/` 폴더로 이동, 로그에 `error`/`패턴 불일치`
  - 치환 후 새 이름이 같은 폴더에 이미 존재(충돌) → 원본을 덮어쓰지 않고 `error/`로 이동, 로그에 `error`/`치환 후 이름 충돌`
  - `.bmp`가 아닌 파일은 전혀 건드리지 않음
- 상태: 완료 (서브에이전트 검증 통과, 2026-07-13)
- 비고:
  - `error/` 폴더는 각 하위폴더 안에 개별 생성됨 (상위 폴더에 통합 error 폴더 없음)
  - rename은 원본을 직접 변경(copy 아님) — 되돌리기 기능 없으므로 실행 전 백업 권장
