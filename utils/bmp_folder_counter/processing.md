# bmp_folder_counter — processing.md

- 경로: `utils/bmp_folder_counter/`
  - `count_bmp.py`: 유일한 파일, 실행 진입점 (GUI 없음)
- 목적: 상위 폴더 구조가 `[상위폴더] > [1단계 하위폴더 여러개] > [2단계 하위폴더 여러개]`일 때, 1단계 하위폴더 중 **이름순 정렬 기준 첫번째 폴더**만 골라 그 안의 2단계 하위폴더별 `.bmp` 파일 개수(재귀 포함)를 표로 집계한다.
- 의존성: 없음 (표준 라이브러리 `os`, `csv`, `sys`만 사용)
- 버전: v1 (2026-07-13)
- 사용법:
  ```
  cd "E:\46 util"
  .venv\Scripts\python.exe utils\bmp_folder_counter\count_bmp.py "D:\path\to\top_folder"
  ```
  - 인자 없이 실행하면 `input()`으로 경로를 물어봄.
  - 콘솔에 표를 출력하고, 입력받은 상위 폴더 안에 `bmp_count_result.csv`(utf-8-sig), `bmp_count_result.md` 두 파일을 생성한다.
- 알고리즘:
  - `os.scandir` + `sorted`로 1단계 하위폴더 이름순 정렬 후 첫번째 항목 선택
  - 그 폴더의 2단계 하위폴더도 동일하게 이름순 정렬
  - 각 2단계 폴더는 `os.walk`로 하위의 하위폴더까지 전부 재귀 탐색하여 `.bmp`/`.BMP`(대소문자 무시) 파일 개수 카운트
  - 결과 테이블: 하위폴더명 / bmp 개수, 마지막 행에 합계
- Edge case 처리:
  - 상위 폴더가 없거나 폴더가 아니면 에러 메시지 출력 후 exit code 1
  - 1단계 하위폴더가 하나도 없으면 에러 메시지 출력 후 exit code 1
  - 2단계 하위폴더가 하나도 없으면 "(2단계 하위폴더 없음)" 안내와 함께 빈 결과(합계 0) 저장 (에러 아님)
- 상태: 완료 (서브에이전트 검증 통과, 2026-07-13)
- 비고:
  - 2단계 폴더 목록만 대상이며, 1단계 폴더가 여러 개 있어도 정렬 기준 첫번째 폴더 하나만 처리한다. 다른 1단계 폴더들은 무시된다.
