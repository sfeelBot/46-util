## 검증 요약 (2026-07-09, 폴더 스캔/일괄 적용 비동기화 + 체크 개수 표시 + 파일명·경로 복사)

- 서브에이전트로 독립 검증을 시도했으나 세션 한도(session limit)로 중도 실패하여, 대신 직접 실제 `MainWindow`를 띄워(`QT_QPA_PLATFORM=offscreen`) 검증함.
- **폴더 스캔 비동기화**(`FolderScanWorker`): `_on_select_folder()` 호출 직후(이벤트 루프 진행 전) 워커가 설정되고 "폴더 선택" 버튼이 비활성화되며 리스트가 아직 비어있음을 확인 → 진짜로 백그라운드에서 도는 것이지 동기적으로 즉시 끝나는 게 아님. 이후 이벤트 루프를 돌리면 정상적으로 리스트가 채워짐.
- **마스킹 일괄 적용 비동기화**(`ApplyWorker`): `_on_apply(scope='all')` 호출 직후 워커가 설정되고 적용 버튼이 비활성화됨. `progress(done, total)` 시그널이 이미지 개수만큼 정확히 emit됨(예: 3개 → (1,3)(2,3)(3,3)). 완료 후 `masked/`에 실제 저장, 원본 파일은 그대로 보존됨을 확인.
- **체크 개수 표시**: 개별 체크박스 클릭, "전체 체크"/"전체 해제", "선택 삭제" 이후 모두 "체크됨: N / 총 M개" 라벨이 정확히 갱신됨을 확인.
- **파일명/경로 복사**: 목록 항목 선택 후 Ctrl+C(`_copy_current_filename`)로 파일명이 클립보드에 복사됨을 확인. 우클릭 컨텍스트 메뉴의 "파일명 복사"/"전체 경로 복사"도 (모달 `QMenu.exec_`를 액션 선택으로 패치해) 각각 파일명/전체 경로가 정확히 클립보드에 들어감을 확인.
- 발견된 버그 없음.

## 검증 요약 (2026-07-09, 하위 폴더 스캔 + 폴더 누적 로드 + 목록 삭제 기능 추가)

서브에이전트가 독립적으로 검증 (코드는 건드리지 않고 실행/테스트만 수행). 발견된 버그 없음.
- `list_images(folder, recursive=)`: 하위 폴더(2단계 depth) 포함 임시 폴더로 `recursive=False`/`True` 각각 실제 실행해 스캔 범위가 기대대로 다름을 확인.
- 폴더 재선택 시 누적: 같은 폴더 재선택 시 중복 미추가, 다른 폴더 선택 시 기존 목록 유지한 채 이어붙여짐을 실제 `MainWindow`(`QFileDialog` 몽키패치)로 확인.
- 선택/전체 삭제: 현재 표시 중인 이미지가 삭제 대상에 포함된 경우 남은 이미지로 자동 전환(빈 화면 방치 없음), 전체 삭제 시 리스트/뷰어 완전히 초기화됨을 확인.
- **가장 중요한 확인**: 삭제 시나리오 종료 후에도 디스크상의 원본 이미지 파일이 전부 그대로 존재함 — 목록/메모리에서만 제거되고 실제 파일은 삭제되지 않음을 확인.
