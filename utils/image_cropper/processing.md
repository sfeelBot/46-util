# image_cropper — processing.md

## 목적

폴더 내 이미지에서 복수의 ROI(관심 영역)를 GUI로 지정하고, 각 영역을 개별 파일로 크롭 저장하는 도구.

## 지원 포맷

| 포맷 | 비고 |
|------|------|
| JPG / JPEG | 8-bit RGB |
| PNG | 8/16-bit, RGBA 포함 |
| BMP | 8/24-bit |
| TIFF / TIF | 8/16-bit, LZW 압축 저장 |
| RAW | 16-bit unsigned, little-endian. 파일 로드 전 W/H 입력 필수 |

## 사용법

```
.venv\Scripts\python.exe utils/image_cropper/main.py
```

1. **폴더 선택** — 폴더를 고르면 곧바로 목록이 채워지지 않고, 그 폴더(및 하위 폴더) 안에 실제로 존재하는 확장자가 "불러올 확장자" 체크박스로 표시됨
   - "📁 폴더 선택" — 선택한 폴더의 최상위 파일만 스캔
   - "📁 폴더 선택 (하위 폴더 포함)" — 하위 폴더까지 재귀적으로 스캔. 단, 크롭 결과가 담기는 `cropped` 폴더(최상위든 중첩이든)는 자동 제외됨
   - 원하는 확장자를 체크(기본 전부 미체크)한 뒤 "목록 불러오기"를 눌러야 좌측 파일 목록(파일명/폴더 2열 테이블)에 반영됨. 하나도 체크하지 않고 누르면 경고 팝업
   - 목록 열 헤더("파일명"/"폴더")를 클릭하면 해당 열 기준으로 정렬됨
2. **RAW 설정** — RAW 파일 포함 시 상단 W/H 필드에 픽셀 크기 입력
3. **ROI 개수** — 스핀박스로 1~999 지정 (개수 변경은 기존 ROI를 지우지 않음)
4. **ROI 지정** — 아래 세 가지 방법을 섞어서 사용 가능
   - 이미지 위에서 순서대로 마우스 좌클릭 드래그 (다음 빈 번호부터 순서대로 채워짐)
   - "ROI 편집" 패널에 번호/X/Y/W/H 숫자를 직접 입력하고 [적용] — 드래그 없이 좌표 지정
   - 레퍼런스 이미지의 파일명에서 파싱한 XYWH를 그대로 불러오기 (아래 "레퍼런스 이미지" 참고)
5. **크롭 실행**
   - "현재 이미지에 적용" : 현재 파일에만 크롭
   - "폴더 전체에 적용" : 현재 로드된 목록(하위 폴더 포함 스캔이었다면 전체 하위 폴더 포함) 내 모든 이미지에 동일 ROI 적용. 각 이미지는 자신이 속한 폴더의 `cropped/` 하위 폴더에 저장됨

## ROI 개별 편집 / 선택 / 삭제

- 캔버스에서 기존 ROI 사각형을 **클릭**(드래그 아님)하면 해당 ROI가 노란색으로 선택되고, "ROI 편집" 패널의 번호/X/Y/W/H에 현재 값이 자동으로 채워짐
- 패널에서 번호나 좌표를 바꾼 뒤 [적용 (생성/수정)]을 누르면:
  - 새 번호면 새 ROI 생성
  - 이미 존재하는 번호면 해당 ROI를 **덮어쓰기**(대체)로 재지정 — 예: 3번을 선택한 뒤 번호를 5로 바꾸고 적용하면 5번 자리에 동일 좌표로 새로 생기고, 기존 3번은 별도로 [선택 ROI 삭제]로 지워야 함
- [선택 ROI 삭제] — 패널의 번호 스핀박스에 있는 ROI **하나만** 삭제 (전체 삭제는 "ROI 초기화" 버튼)
- 빈 캔버스를 클릭하면 선택 해제 및 (자리가 남아있으면) 새 드래그 시작

## 레퍼런스 이미지 (파일명 기반 ROI 로드)

- 좌측 "레퍼런스 이미지" 목록에서 [추가]로 여러 장의 이미지를 한 번에 선택 가능
- 각 파일명 끝의 `_{idx}_x{x}y{y}w{w}h{h}` 패턴(이 도구의 크롭 출력 파일명 규칙과 동일)을 파싱해서 목록에 표시. 패턴이 안 맞으면 "⚠ 파싱 실패"로 표시되고 로드 대상에서 제외됨
- [ROI 불러오기] — 목록에서 항목을 선택했으면 그 항목들만, 아무것도 선택 안 했으면 목록 전체를 파싱된 XYWH 그대로 현재 이미지에 ROI로 생성/교체
- 불러온 ROI 번호가 "ROI 개수"보다 크면 개수가 자동으로 늘어남
- 좌표는 현재 표시 중인 이미지의 픽셀 좌표계 기준으로 그대로 적용되며, 이미지 범위를 벗어나면 자동 클램프(잘림)됨

## 조작

| 동작 | 방법 |
|------|------|
| 줌인/줌아웃 | 마우스 휠 스크롤 |
| 패닝(이동) | 가운데 마우스 버튼 드래그 |
| ROI 그리기 | 빈 공간에서 좌클릭 드래그 (다음 빈 번호 자동 할당) |
| ROI 선택 | 기존 ROI를 좌클릭 (드래그 아님) |
| ROI 번호/좌표 수정 | 선택 후 "ROI 편집" 패널에서 수정 → [적용] |
| ROI 개별 삭제 | 패널 번호 지정 후 [선택 ROI 삭제] |
| ROI 전체 초기화 | "ROI 초기화" 버튼 |

## 출력 파일명 규칙

```
{원본파일명}_{ROI번호}_x{x}y{y}w{w}h{h}{확장자}
예) photo_1_x100y50w300h200.jpg
```

- XYWH는 원본 이미지 좌표계 기준 픽셀 값
- 파일명에서 XYWH를 읽어 재크롭 가능

## 출력 위치

`{원본폴더}/cropped/` 하위 폴더 (없으면 자동 생성)

## 알고리즘

- **RAW 표시**: `numpy.frombuffer(dtype='<u2').reshape(H,W)` → min-max 정규화 → 8-bit Grayscale QImage
- **RAW 저장**: 크롭된 uint16 배열을 `.tofile()` (little-endian 유지)
- **TIFF**: Pillow `crop()` → `tiff_lzw` 압축 저장
- **PNG/JPG/BMP**: Pillow `crop()` → 동일 확장자로 저장

## 제약 사항

- RAW 파일은 반드시 W/H를 먼저 입력해야 로드됨
- 폴더 전체 적용 시 모든 파일이 동일한 W/H, 동일 ROI를 사용 (RAW 파일 혼합 폴더 주의)
- 다중 프레임 TIFF는 첫 번째 프레임만 처리
- ROI 번호를 이미 사용 중인 번호로 재지정하면 기존 ROI는 경고 없이 덮어써짐 (교환/swap 아님)
- 레퍼런스 이미지의 파일명 패턴은 이 도구의 크롭 출력 규칙(`_{idx}_x{x}y{y}w{w}h{h}`)과 정확히 일치해야 파싱됨
- 하위 폴더 포함 스캔 시 `cropped`라는 이름의 폴더는 깊이와 무관하게 항상 제외됨 (재크롭 방지 목적이므로, 이미지 원본을 실제로 `cropped`라는 이름의 폴더에 보관 중이라면 해당 폴더는 로드되지 않음)
