# folder_suffix_copier QA

이 util에서 발견된 버그/이상 동작/검증 실패 사례를 기록한다.
형식: 발생 일자 / 증상 / 원인 / 해결 방법(또는 미해결 상태).

---

아직 기록된 이슈 없음. (초기 작성 2026-07-15, 서브에이전트 검증 34개 체크 전부 통과)

## 검증 이력

- **2026-07-15 서브에이전트 검증 통과** — `QT_QPA_PLATFORM=offscreen` 환경에서
  `scan_files`/`build_plan` 직접 호출, `CopyWorker.run()` 동기 실행, `MainWindow`
  offscreen 인스턴스화로 총 34개 체크 수행, 전부 통과. 검증 항목: 접미어 규칙
  (중첩/단일 depth/루트 직속 무접미어/한글 폴더명), 확장자 없는 파일 제외,
  출력 폴더가 root 내부일 때 스캔 제외, 대소문자 무시 이름 충돌 번호 부여
  (기존 파일 충돌 + 계획 내 중복), 같은 폴더 모드의 자기충돌 `_2`, 복사 전후
  원본 트리 SHA-1 무변경, GUI 스캔→미리보기→확장자 필터 동작.
- 참고(버그 아님): 같은 폴더 모드를 같은 트리에 반복 실행하면 이전 사본과
  충돌해 `_2`, `_3`… 사본이 계속 늘어난다. 충돌 번호 부여 스펙의 자연스러운
  결과이며 덮어쓰기는 발생하지 않는다.
