# folder_suffix_copier — 상위 폴더명 접미어 복사 도구

## 목적

지정 폴더를 재귀 탐색하여 하위 폴더 안의 파일(bmp/raw 기본, 스캔된 확장자 중 선택 가능)을 찾고,
**지정 폴더 기준 상대경로의 상위 폴더명들을 `_`로 이어붙인 접미어**를 파일명 뒤(확장자 앞)에 붙인
**사본(copy)** 을 만든다. 원본 파일은 절대 수정/이동하지 않는다.

예) 대상 폴더가 `E:\data`이고 파일이 `E:\data\LotA\Cell1\img.bmp`이면
→ `img_LotA_Cell1.bmp` 로 복사된다.

## 상태 / 버전

- v1.0 (2026-07-15) — 최초 작성.

## 사용법

```
.venv\Scripts\python.exe utils\folder_suffix_copier\main.py
```

1. **대상 폴더**를 찾아보기로 지정한다.
2. **저장 방식**을 선택한다.
   - 별도 출력 폴더에 모으기 (기본값): 기본 경로로 `<대상폴더>_renamed`가 자동 제안되며 변경 가능.
   - 원본과 같은 폴더에 생성: 각 원본 옆에 접미어 붙은 사본을 만든다.
3. **[스캔]** 버튼을 누르면 재귀 탐색 후, 발견된 확장자들이 체크박스로 표시된다
   (`.bmp`, `.raw`는 기본 체크). 체크된 확장자만 복사 대상이 된다.
4. 테이블에서 `상대경로 | 변경 전 | 변경 후` 미리보기를 확인한다.
   이름 충돌로 번호가 붙는 파일은 변경 후 이름이 빨간색으로 표시된다.
5. **[실행 (복사)]** 버튼 → 확인 팝업 → 백그라운드 스레드에서 복사 진행.
   하단 로그창에 파일마다 `변경 전 → 변경 후`가 출력되고, 완료 시 성공/실패 건수를 요약한다.

## 알고리즘 / 동작 규칙

- 탐색: `os.walk` 재귀. 확장자 없는 파일은 제외. 출력 폴더가 대상 폴더 안에 있으면
  그 하위는 탐색에서 자동 제외 (재실행 시 결과물 중복 스캔 방지).
- 접미어: 대상 폴더 기준 상대경로의 폴더명들을 `_`로 연결.
  **대상 폴더 바로 아래에 있는 파일은 접미어 없이 원본명 그대로** 복사한다.
- 이름 충돌: 대상 폴더에 이미 존재하는 파일명(대소문자 무시) 또는 계획 내 중복 이름은
  `_2`, `_3` … 번호를 붙여 모두 복사하고 로그에 표시한다.
  "같은 폴더" 모드에서 접미어가 없는 파일(대상 폴더 직속)은 원본 자신과 충돌하므로
  자동으로 `_2` 번호가 붙는다 (원본 덮어쓰기 방지).
- 복사: `shutil.copy2` (타임스탬프 등 메타데이터 보존). 파일 단위 실패는 로그에 남기고 계속 진행.
- 실행 직전에 계획을 최신 파일 시스템 상태로 재계산한다.

## 구조

```
utils/folder_suffix_copier/
├── main.py         # PyQt5 GUI + 로직 (단일 파일)
├── processing.md   # 이 문서
└── QA.md           # 버그/이슈 기록
```

- `scan_files(root, exclude_dir)` — 재귀 파일 수집 + 확장자 집합 반환 (GUI 비의존, 테스트 가능)
- `build_plan(root, files, separate_output, out_dir)` — (원본, 대상, 상대경로, 번호부여 여부) 계획 생성 (GUI 비의존)
- `CopyWorker(QThread)` — 복사 실행, 진행률/로그 시그널
- `MainWindow(QWidget)` — GUI

## 제약사항

- 확장자 없는 파일은 대상에서 제외된다.
- 폴더명에 이미 `_`가 포함되어 있으면 접미어 구분이 모호해질 수 있다 (동작에는 문제 없음).
- 매우 깊은 경로에서는 Windows 경로 길이 제한(260자)에 걸릴 수 있다.
