# y_axis_masker — processing.md

## 목적

이미지에서 지정한 y좌표 아래(하단) 영역을 전부 마스킹 처리하는 도구. Before(원본 + 경계선) / After(마스킹 결과) 뷰어를 나란히 보여주며, 폴더 단위 일괄 처리를 지원한다.

## 지원 포맷

| 포맷 | 비고 |
|------|------|
| JPG / JPEG | 8-bit RGB |
| PNG | 8/16-bit, RGBA 포함 |
| BMP | 8/24-bit |
| TIFF / TIF | 8/16-bit, LZW 압축 저장 |
| RAW | 16-bit unsigned, little-endian. 파일 로드 전 W/H 입력 필수 |

## 사용법

```
.venv\Scripts\python.exe utils/y_axis_masker/main.py
```

1. **폴더 선택** — 이미지가 있는 폴더를 선택하면 좌측 목록에 파일이 나열됨 (체크박스 포함)
2. **RAW 설정** — RAW 파일 포함 시 상단 W/H 필드에 픽셀 크기 입력 (변경 시 현재 RAW 이미지 자동 재로드)
3. **y좌표 지정** — 세 가지 방법을 섞어서 사용 가능, 모두 동일 값으로 연동됨
   - 숫자 입력 (SpinBox)
   - 슬라이더
   - Before 뷰어의 빨간 경계선을 클릭 후 드래그
4. **마스킹 채우기 방식 선택** (콤보박스)
   - **검정** — y 이하 영역을 0으로 채움
   - **흰색** — dtype 최대값으로 채움 (8bit=255, RAW 16bit=65535)
   - **가우시안 블러** — 강도 슬라이더(sigma 1~150)로 조절, 원본을 블러링한 값으로 대체
   - **선택 영역 평균값** — "샘플 영역 지정" 버튼 → Before 뷰어에서 자유롭게 드래그하여 ROI 지정 → 해당 영역의 평균값(채널별)으로 채움
   - **스포이드** — "색상 추출" 버튼 → Before 뷰어에서 픽셀 클릭 → 그 색상으로 채움
5. **After 뷰어**에서 실시간 미리보기 확인 (y/모드/강도 변경 시 즉시 갱신)
6. **적용**
   - "현재 이미지 적용" : 현재 파일에만 저장
   - "폴더 전체 적용" : 폴더 내 모든 이미지에 동일 설정 적용
   - "체크된 이미지만 적용" : 좌측 목록에서 체크된 파일에만 적용
   - 검색창으로 파일명을 필터링해 리스트를 좁힌 뒤 체크/해제 가능

## 조작

| 동작 | 방법 |
|------|------|
| 줌인/줌아웃 (Before/After 공통) | 마우스 휠 스크롤 |
| 패닝(이동) | 가운데 마우스 버튼 드래그 |
| y 경계선 이동 | Before 뷰어에서 빨간 선 근처를 클릭 후 드래그 |
| 샘플 ROI 지정 | "샘플 영역 지정" 클릭 → Before 뷰어에서 좌클릭 드래그 (이미지 어디든 가능) |
| 스포이드 색상 추출 | "색상 추출" 클릭 → Before 뷰어에서 좌클릭 |

## 동작 규칙 (사용자 확정 사항)

- y값은 폴더 전체/체크 적용 시 **공통 값 하나**로 모든 이미지에 동일 적용됨 (이미지별 개별 y값은 지원하지 않음)
- "선택 영역 평균값"/"스포이드"로 계산된 채우기 색상은 **현재 이미지에서 한 번 계산한 값을 고정값으로 재사용**하며, 일괄 적용 시 이미지마다 다시 계산하지 않음
- 컬러(RGB/RGBA) 이미지의 평균값/스포이드 값은 **채널별로 개별 계산·적용**됨
- 마스킹 모드를 바꾸면 샘플/스포이드 값은 초기화됨 (다시 지정 필요)

## 출력 위치 / 파일명 규칙

`{원본폴더}/masked/` 하위 폴더 (없으면 자동 생성), **원본과 동일한 파일명**으로 저장

## 알고리즘

- **로드**: `masking.load_array()` — RAW는 `numpy.frombuffer(dtype='<u2').reshape(H,W)`, 그 외는 Pillow `np.array(Image.open(...))` (원본 dtype 유지: uint8 또는 uint16)
- **표시(정규화)**: `masking.array_to_qpixmap()` — 16/32bit 그레이스케일은 이미지의 min/max 기준으로 8bit 정규화, 그 외는 그대로 QImage 변환
- **마스킹**: `masking.apply_mask(image, y, mode, gaussian_sigma=, fill_value=)`
  - `black`/`white`: 상수 채움 (dtype 기준 0 또는 최대값)
  - `gaussian`: `cv2.GaussianBlur(image, (0,0), sigmaX=sigma, sigmaY=sigma)` 결과로 y 이하 영역 대체
  - `constant`: GUI에서 미리 계산한 `fill_value`(스칼라 또는 채널별 튜플)로 채움 — 평균값/스포이드 모드가 이 경로를 공유
- **저장**: RAW는 `astype('<u2').tofile()`, TIFF는 `tiff_lzw` 압축, 나머지는 Pillow 기본 저장

## 제약 사항

- RAW 파일은 반드시 W/H를 먼저 입력해야 로드됨
- 폴더 전체/체크 적용 시 모든 파일이 동일한 W/H(RAW인 경우)를 사용 — RAW 파일 혼합 폴더 주의
- "선택 영역 평균값"/"스포이드"의 고정값은 다른 비트뎁스·채널 수 이미지가 섞인 폴더에서는 값 범위가 맞지 않을 수 있음 — 동일 포맷 폴더 사용 권장
- 다중 프레임 TIFF는 첫 번째 프레임만 처리
- 가우시안 모드는 sigma가 클수록(최대 150) 처리 시간이 늘어날 수 있음
